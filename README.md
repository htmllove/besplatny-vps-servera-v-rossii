## 📱 Как пользоваться

1. Установите VPS-клиент с поддержкой подписок:
   - **Android:** [v2rayNG](https://github.com/2dust/v2rayNG), [Hiddify](https://github.com/hiddify/hiddify-app), [NekoBox](https://github.com/MatsuriDayo/NekoBoxForAndroid)
   - **iOS:** Streisand, Happ, Shadowrocket, [Hiddify](https://github.com/hiddify/hiddify-app)
   - **Windows / macOS / Linux:** [Hiddify](https://github.com/hiddify/hiddify-app), [Nekoray](https://github.com/MatsuriDayo/nekoray), [v2rayN](https://github.com/2dust/v2rayN)
2. Скопируйте ссылку из таблицы (ПКМ → «Копировать адрес ссылки»).
3. В клиенте выберите **«Добавить подписку» / «Import subscription»** и вставьте ссылку.
4. Обновите подписку, выберите сервер с наименьшим пингом и подключайтесь.

## ⚠️ Дисклеймер

- Это **публичные бесплатные серверы от энтузиастов** — не используйте их для передачи чувствительных данных без HTTPS.
- Работоспособность серверов не гарантируется: если подписка перестала работать — обновите её или попробуйте другую из списка.
- Репозиторий носит информационный характер.
